# Attribution and provenance

The source notebook in the repository (`Victory hamoye.ipynb`) contains a detailed Planet/SCCON competition workflow, but it does not identify its original author or provide a source URL. The implementation therefore cannot currently be represented as wholly original work.

Before using this project in an application or presenting it publicly:

1. Identify the original notebook or repository from which the implementation was adapted.
2. Confirm its licence and reuse conditions.
3. Add the author's name, source URL and licence here, and distinguish inherited code from changes made in this repository.
4. If the original source cannot be identified, replace the inherited implementation with a newly written and independently tested pipeline rather than claiming authorship.
