# Appliance Energy Consumption Prediction

This project investigates the prediction of household appliance energy consumption from indoor environmental measurements and time-based features.

## Dataset

The project uses the [UCI Appliances Energy Prediction dataset](https://archive.ics.uci.edu/dataset/374/appliances+energy+prediction). Download `energydata_complete.csv` and place it at `data/raw/energydata_complete.csv`. The dataset is not included in this repository.

## Approach

- Inspect the dataset and missing values.
- Extract hour, day-of-week and month from the timestamp.
- Preserve chronological order and use the first 80% of observations for training and the final 20% for testing.
- Compare a mean baseline, linear regression and random forest regression.
- Fit imputation and scaling within model pipelines to prevent preprocessing leakage from the test set.
- Evaluate with MAE, RMSE and R².

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook notebooks/appliance_energy_prediction.ipynb
```

On Windows, activate the environment with `.venv\\Scripts\\activate`.
