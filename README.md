# Hamoye AI and Data Science Projects

This repository contains applied machine-learning and data-analysis work completed during Hamoye training. The projects are being organised so that each has a clear problem statement, reproducible setup and evaluation approach.

## Featured projects

### Appliance Energy Consumption Prediction

A regression project using environmental sensor readings and time features to estimate household appliance energy consumption. It compares a mean baseline, linear regression and random forest using a chronological holdout. See [`appliance-energy-prediction/`](appliance-energy-prediction/README.md) for dataset instructions and the notebook.

### Amazon Satellite-Image Multi-Label Classification

An adapted computer-vision workflow for classifying satellite images with multiple land-cover and human-activity labels. It explores an ImageNet-pretrained ResNet-18, class imbalance, per-class thresholds and test-time augmentation. The original implementation's provenance has not yet been established, and the cleaned notebook has not been rerun end to end. See [`amazon-deforestation-classification/`](amazon-deforestation-classification/README.md) for its current status and attribution requirements.

## Original notebooks

The notebooks from the original coursework are retained at the repository root for reference. The project directories contain cleaned working copies and documentation; neither project should be treated as fully validated until its setup and results have been reproduced.
