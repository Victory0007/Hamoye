# Hamoye AI and Data Science Projects

This repository contains applied machine-learning and data-analysis work completed during Hamoye training. The projects are being organised so that each has a clear problem statement, reproducible setup and evaluation approach.

## Featured project

### Appliance Energy Consumption Prediction

A regression project using environmental sensor readings and time features to estimate household appliance energy consumption. It compares a mean baseline, linear regression and random forest using a chronological holdout. See [`appliance-energy-prediction/`](appliance-energy-prediction/README.md) for the dataset instructions and notebook.

## Original notebooks

The notebooks from the original coursework are retained at the repository root for reference. They have not been presented as independently reproducible projects because their datasets and execution environments are not included here.
